# 🌱 Start from zero — foundations

_Never written Java or used a terminal? Perfect — **start here.** These are short primers (about 5–10
minutes each) that give you exactly enough to begin the course feeling confident, with nothing left
mysterious. Total: roughly an hour._

> [!NOTE]
> You do **not** need to memorise any of this. Read it, nod, move on. The course then re-teaches every
> idea *in context* as you build the real app — that's when it sticks. Coming back here later is normal.
